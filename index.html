工作原理与限制

分片并发

通过 HTTP Range 把文件切成多段，由多个 Web Worker 同时请求，合并后统一保存，理论上可跑满带宽。

需要服务端支持

目标站点必须返回 206 Partial Content 且开放 CORS；否则自动降级为单连接流式下载。

内存占用

分片在内存中合并后写入磁盘，超大文件（建议 < 1GB）可能占用较多内存，请留意浏览器提示。

跨域墙

浏览器无法绕过服务器未授权的跨域限制。若日志提示 CORS，请换用允许跨域的直链或自建中转代理。
